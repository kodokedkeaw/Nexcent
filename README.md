## Landing Page (Frontend Project)
โปรเจกต์นี้เป็นหน้าเว็บ Landing Page ที่ออกแบบตามแบบจาก Figma(Free Template)
โดยพัฒนาโดยใช้ HTML, CSS, SCSS, และ JavaScript เพื่อฝึกฝนทักษะการแปลงดีไซน์เป็นโค้ด (Design to Code)

## รายละเอียดโปรเจกต์
- Design Source: [Figma Free Template](https://www.figma.com/community/file/1222060007934600841/minimal-landing-page-design-website-home-page-design-agency-website-ui-design)  
- Tech Stack:
  - HTML5
  - CSS / SCSS
  - JavaScript
- Concept: ฝึกฝนการเขียนโค้ดตามดีไซน์จริงจากนักออกแบบ
- Responsive: รองรับการแสดงผลบนมือถือ แท็บเล็ต และเดสก์ท็อป

## ฟีเจอร์ที่พัฒนา
- โครงสร้างเว็บด้วย HTML ที่อ่านง่ายและเป็นระเบียบ  
- ใช้ SCSS แยกไฟล์ตามโครงสร้าง component  
- Animation และ Transition ด้วย CSS และ JS  
- Navigation bar แบบ responsive  
- ส่วน Nav,Hero, Section, และ Footer ตามดีไซน์ใน Figma
